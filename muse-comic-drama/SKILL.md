# Muse 漫剧生成

核心判断：长视频质量差，多半不是视频模型不行，而是**整片提示词和首帧没定好**。
所以先把方案和首帧定死，再让视频模型按图生成；人负责拍板、审图、选片。

> 方法来源：Jarvis（@jarvis11x）《如何用 Muse+豆包 Work+ChatGPT，做出高质量稳定的长视频》，
> https://x.com/jarvis11x/status/2111026168526746057 。本 Skill 为转述整理，不含原文。

## 0. 开工前先问清（缺一项就问，不要猜）

| 项 | 默认 |
|---|---|
| 题材 / 剧本（或一句话想法） | 必填 |
| 总时长 | 3 分钟 → 18 镜（Muse 视频固定 10 秒/镜） |
| 画幅 | 16:9，成片 1280×720 |
| 画风 | 例：国风水墨、吉卜力、赛璐璐漫画、写实 |
| 首帧来源 | `muse`（Muse 自己出图）或 `external`（用户拿去 ChatGPT 等更强的生图工具出图，再传回来） |
| 是否需要对白 | 默认无原生对白，用字幕/旁白；原生对白很难稳定 |

镜头数 = 总秒数 ÷ 10，向上取整。

## 1. 整片方案（Gate：用户确认后才进入下一步）

1. 先调研：搜索同题材的爆款短视频（抖音 / TikTok / B 站），以及 Seedance 等视频模型的官方提示词技巧。
2. 输出**规律总结**（5～8 条），讲清这类片子为什么好看：构图比例、前中后景层次、色彩、镜头速度、节奏。
3. 输出**整片结构**：开场 → 推进 → 高潮 → 收尾，各段落占哪几镜。
4. 按 [templates/storyboard.md](templates/storyboard.md) 写出完整分镜表。每镜必须有：
   - `0s` 首帧画面（这就是首帧图的提示词来源）
   - `0–3s / 3–7s / 7–10s` 画面怎么动、镜头怎么动
   - 结束构图 + 下一镜怎么接
5. 自检后交给用户：每镜拍什么、怎么动、停在哪、下一镜能否接上。用户确认前不出图。

写法要点：
- 一镜只做一件事，动作要简单可拍；复杂动作拆成两镜。
- 镜头运动用明确词：缓慢前推、轻微上摇、横移、环绕、固定机位。
- 第一镜别把东西全露出来，留给后面逐步展开。

## 2. 锁定资产（Gate：用户确认参考图后锁定）

按 [templates/asset-bible.md](templates/asset-bible.md) 为每个**人物、场景、道具**写一段定稿描述，并出参考图给用户看。

- 用户满意后，这段描述就是**锁定文本**：之后所有分镜提示词里**逐字复制**，一个字都不改，不换说法、不加形容词。
- 人物的外貌、发型、服装、配色必须写全；场景写清主体建筑/地标、时间、光线。
- 需要改资产时，回到这一步重新确认，并同步替换所有分镜里的引用。

## 3. 逐镜首帧（Gate：每张首帧都经用户确认）

- 提示词 = 画风前缀 + 该镜 `0s` 画面 + 引用到的锁定资产文本 + 画幅。
- `首帧来源 = muse`：自己逐镜出图。
- `首帧来源 = external`：把“全片风格说明 + 全部锁定资产 + 每镜首帧提示词”整理成一份可直接粘贴的文档交给用户，
  请他们用更强的生图工具（如 ChatGPT）先读懂全片风格、再一镜一张出图，然后把图按镜号传回。
- 审图看四件事：**人物、构图、场景、光线**。不满意先改图，不要带着有问题的首帧去生成视频。
- 文件命名：`frames/S01.png`、`frames/S02.png` ……

## 4. 逐镜生成视频与选片

- 一次只做一镜：首帧图 + 该镜 10 秒提示词（`0–3s / 3–7s / 7–10s` + 结束构图）。
- 每条生成后先自查，再交用户确认；确认一条，再做下一条。检查：
  1. 这一镜本身：有无崩坏、变形、多余物体、文字乱码
  2. 和前后镜放在一起：人物是否变样、动作/运镜是否跑偏、切镜是否顺
- 同一镜可以多生成几条让用户挑。选中的存为 `shots/S01.mp4` ……
- **止损规则**：同一镜试了 10～15 次仍不对，停止加次数，改为：简化动作、换一种拍法（换机位/景别），
  或把对白改成字幕。继续堆次数通常只是反复撞同一个问题。

## 5. 拼接成片

- 用 [scripts/concat.sh](scripts/concat.sh)：先把所有镜头统一到 1280×720、30fps（不同比例的镜头加黑边，不拉伸），再按镜号顺序拼接。
  ```bash
  bash scripts/concat.sh shots out/final.mp4
  ```
- 加音乐时单独一步混音，不要和拼接写在一起，方便换版本；水印/字幕位置单独确认。

## 6. 整片验收（Gate：用户说通过才算完成）

从头看到尾，重点看：
- 每个切镜点是否顺；人物和场景是否前后一致
- 音乐、环境声和画面情绪是否匹配
- 水印、字幕是否遮挡主体

交付物清单：分镜表、资产锁定表、`frames/`、`shots/`、`out/final.mp4`、一份返工记录（哪几镜重试了多少次、为什么）。

## 原则

- 方案和首帧决定上限，视频模型决定稳定性；影响画质的环节用最强的工具，需要大量重试的环节用成本合适的工具。
- 每次只改一个环节，看效果再动下一个。
- 哪张图能用、哪条留下、成片要不要改，由用户拍板；你负责把选项准备好、把问题说清楚。
